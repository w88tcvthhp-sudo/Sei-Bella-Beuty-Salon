# Sei Bella Beauty — Image Folder Guide

The website looks complete right now using elegant branded placeholders.
To replace each placeholder with a real photo, drop a JPEG/PNG into this
`images/` folder using **exactly** the filename listed below (lowercase, same spelling).
As soon as a file is present, it automatically appears on the site — no code editing needed.

Tip: keep photos under ~400 KB each for fast mobile loading. Square or portrait works best for the gallery.
